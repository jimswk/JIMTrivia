Integrasi Google Sheets (Rekod Kehadiran Pengunjung)

Rekod pengunjung akan dihantar terus ke Google Sheets (tanpa keputusan goresan).

Langkah Penyediaan Google Sheets:

  1. Buka Google Sheets baharu, klik menu Extensions > Apps Script.
  2. Padam kod asal dan tampal kod di bawah, kemudian klik Deploy > New deployment.
  3. Pilih jenis Web app, tetapkan Who has access kepada Anyone, dan salin URL Web App ke ruangan di atas.
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Tarikh", "Masa", "Nama Pengunjung", "Kategori", "Julat Umur"]);
  }
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.date, data.timestamp, data.name, data.category, data.ageRange]);
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
